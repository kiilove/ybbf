# 미디어 페이지 기획 (`/media`)

> **디자인 참조: Lando Norris Off-Track 페이지**
> 에디토리얼 매거진 느낌의 비대칭 레이아웃

---

## 컨셉

대회 준비상황, 핵심공략법, 인터뷰, 대회 요약 등
**공식적인 정보와 영상을 아카이빙하는 콘텐츠 허브**.
SNS가 아닌 "공식 미디어 센터"로서의 권위를 부여.

---

## 섹션 구성

### 섹션 1: 히어로
- **"MEDIA"** 거대 타이포 (Off-Track의 "OFFTRACK" 스타일)
- 최신 피쳐드 영상 썸네일이 타이포 위에 오버랩
- 부제: `"대회의 모든 순간을 기록합니다"`

### 섹션 2: 카테고리 필터
- 탭: `전체` | `대회 하이라이트` | `인터뷰` | `트레이닝` | `공지`
- 미니멀 텍스트 탭, 선택 시 네온 라임 언더라인
- 스크롤 시 상단 고정 (sticky)

### 섹션 3: 콘텐츠 그리드
- Off-Track 에디토리얼 레이아웃:
  - 첫 번째: 풀폭 피쳐드 카드 (대형 썸네일 + 제목 + 설명)
  - 나머지: 2~3컬럼 비대칭 스태거드 그리드
- 카드 디자인:
  - 썸네일 (호버 시 ▶ 재생 아이콘 + 스케일업)
  - 카테고리 태그 (네온 라임 배지)
  - 제목 (볼드 타이포) + 날짜
  - 메타데이터 라벨

### 섹션 4: 영상 재생
- 모달 또는 인라인 비디오 플레이어
- YouTube 임베드 or 자체 mp4

---

## 데이터 모델

```typescript
interface MediaItem {
  id: string;
  title: string;
  category: 'highlight' | 'interview' | 'training' | 'notice';
  thumbnail: string;
  videoUrl?: string;       // YouTube URL or mp4 path
  date: string;            // 2026-05-01
  description: string;
  featured?: boolean;      // 피쳐드 대형 카드 여부
  relatedLegendIds?: string[];
}
```

## 메인페이지 연결

- 기존 `HorizontalGallery` → **"MEDIA"** 가로 스크롤 프리뷰
- 최신 미디어 5~8개를 가로 스크롤로 표시
- `[미디어 센터 →]` CTA 버튼 → `/media`
