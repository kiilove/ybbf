# 대회 시스템 기획 (`/competition`)

> **성격**: 독립 시스템급 모듈  
> 접수 → 실시간 중계 → 투표/응원 → 결과 발표까지  
> 대회의 전체 라이프사이클을 하나의 허브에서 관리

---

## 시스템 개요

### 라이프사이클 (Phase)

```
[UPCOMING] → [REGISTRATION] → [CLOSED] → [LIVE (D-day Only)] → [RESULT]
  예고         접수 중         마감      대회 당일 한정       결과 발표
   │              │              │              │
   │   📩 접수시작 알림    📩 마감+명단알림   📩 LIVE시작 알림
   │
   📩 사전 알림 등록
```

- `status` 값 하나로 전체 페이지 UI가 전환됨
- 관리자(Admin)가 상태를 수동 전환하거나, 날짜 기반 자동 전환
- **LIVE는 대회 당일(D-day)에만 활성화** — 관리자가 수동으로 ON/OFF

---

## 라우트 구조

| 경로 | 설명 |
|------|------|
| `/competition` | 메인 허브 (현재 Phase에 따라 UI 자동 전환) |
| `/competition/register` | 접수 폼 (REGISTRATION 상태에서만 활성) |
| `/competition/live` | 실시간 중계 + 투표 + 응원 댓글 |
| `/competition/results` | 최종 결과 + 시상 + 갤러리 |

## Phase별 UI 구성

### Phase 1: UPCOMING (예고)
- 거대 타이포: **"2026 용인시장배"**
- D-Day 카운트다운 타이머
- 지난 대회 하이라이트 영상 (Cloudflare Stream VOD)
- 대회 개요 (일시, 장소, 부문)
- **알림 등록 CTA**: `접수 시작 알림 받기` 버튼
  - 이메일 또는 카카오 알림톡 중 선택
  - 등록 시점: 사전 언제든
  - 발송 시점: 접수 시작일, 마감 3일 전, D-day 라이브 시작 시

### Phase 2: REGISTRATION (접수 중)
- 접수 폼 + 접수 현황 실시간 카운터
- **접수 필드**:

| 필드 | 타입 | 필수 | 비고 |
|------|------|------|------|
| 성명 | text | ✅ | |
| 생년월일 | date | ✅ | |
| 연락처 | tel | ✅ | |
| 소속 클럽/체육관 | select + text | ✅ | 등록 클럽 선택 or 직접 입력 |
| 출전 부문 | select | ✅ | 보디빌딩/클래식피지크/스포츠모델/유스 |
| 체급 | select | ✅ | 부문별 체급 동적 변경 |
| 프로필 사진 | file | ⬡ | 선수 카드 생성용 |
| 경력 사항 | textarea | ⬡ | |

- 접수 완료 시: 접수번호 발급 + 확인 문자/이메일
- 사이드바: 실시간 접수 현황 (총 접수 인원, 부문별 인원)

### Phase 3: CLOSED (접수 마감)
- **출전 선수 명단 공개** (부문별/체급별 정렬)
- 선수 카드: 사진 + 이름 + 소속 + 체급
- D-Day 카운트다운 (대회 당일까지)
- 대회 당일 타임테이블 공개

### Phase 4: LIVE (실시간 중계) — ⚡ D-day 당일 한정
> 이 Phase가 시스템의 핵심  
> **대회 당일에만 관리자가 수동으로 LIVE 모드를 ON**  
> LIVE 전환 시 알림 등록자에게 📩 푸시 발송

#### 4-1. 실시간 영상
- Cloudflare Stream 임베드 (라이브 스트리밍)
- 현재 진행 중인 부문/체급 표시
- 현재 무대 위 선수 프로필 카드 실시간 전환
- 대회 종료 후 자동으로 VOD 전환 (같은 URL 유지)

#### 4-2. 실시간 투표
- **"관중 인기상"** 투표 시스템
- 현재 무대 위 선수들에게 투표 가능
- 투표 결과 실시간 바 차트 (WebSocket or Firebase RTDB)
- 1인 1표 제한 (IP + 디바이스 핑거프린트)

#### 4-3. 응원 댓글
- 실시간 채팅/댓글 피드 (우측 사이드바)
- 닉네임 입력 후 댓글 작성 (비로그인)
- 비속어 필터링
- 스크롤 자동 하단 고정
- 특수 이모지 반응 (💪🔥🏆👏)

#### 4-4. 레이아웃

```
┌─────────────────────────────────────────┐
│  현재 부문: 클래식 피지크 -180cm        │
├───────────────────────┬─────────────────┤
│                       │  💬 실시간 채팅  │
│   🎥 라이브 스트림     │  닉네임: ___    │
│   (Cloudflare Stream) │  메시지: ___    │
│                       │  [보내기]        │
│                       │                 │
│                       │  홍길동: 화이팅!  │
│                       │  김철수: 💪💪    │
├───────────────────────┴─────────────────┤
│  🗳️ 관중 인기상 투표                     │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐   │
│  │선수1 │ │선수2 │ │선수3 │ │선수4 │   │
│  │ 42%  │ │ 28%  │ │ 18%  │ │ 12%  │   │
│  └──────┘ └──────┘ └──────┘ └──────┘   │
└─────────────────────────────────────────┘
```

### Phase 5: RESULT (결과 발표)
- **시상 결과**: 부문별 순위 (금/은/동 + 특별상)
- 관중 인기상 최종 결과
- 대회 포토 갤러리
- 대회 풀영상 다시보기 (Cloudflare Stream VOD)
- 다음 대회 예고 배너

## 데이터 모델

```typescript
// 대회 정보
interface Competition {
  id: string;
  title: string;              // "2026 용인시장배 보디빌딩 대회"
  date: string;               // "2026-10-15"
  venue: string;              // "용인시 체육관"
  status: 'upcoming' | 'registration' | 'closed' | 'live' | 'result';
  registrationStart: string;  // 접수 시작일
  registrationEnd: string;    // 접수 마감일
  categories: Category[];     // 출전 부문
  streamUrl?: string;         // Cloudflare Stream 라이브 URL
  vodUrl?: string;            // 대회 종료 후 다시보기 URL
}

// 부문 & 체급
interface Category {
  id: string;
  name: string;               // "클래식 피지크"
  classes: string[];           // ["-175cm", "-180cm", "+180cm"]
}

// 접수 데이터
interface Registration {
  id: string;
  competitionId: string;
  name: string;
  birthDate: string;
  phone: string;
  clubId?: string;
  clubName: string;
  categoryId: string;
  classId: string;
  profileImage?: string;
  career?: string;
  registeredAt: string;
  registrationNumber: string;  // "YBBF-2026-001"
}

// 실시간 투표
interface Vote {
  competitionId: string;
  categoryId: string;
  athleteId: string;
  voterId: string;             // IP 기반 or 디바이스 핑거프린트
  timestamp: string;
}

// 응원 댓글
interface LiveComment {
  id: string;
  competitionId: string;
  nickname: string;
  message: string;
  timestamp: string;
  reaction?: '💪' | '🔥' | '🏆' | '👏';
}

// 대회 결과
interface CompetitionResult {
  competitionId: string;
  categoryId: string;
  classId: string;
  rankings: {
    rank: number;              // 1, 2, 3...
    athleteId: string;
    athleteName: string;
    club: string;
    specialAward?: string;     // "관중 인기상", "베스트 포저" 등
  }[];
}
```

## 기술 스택 매핑

| 기능 | 기술 | 비고 |
|------|------|------|
| 접수 폼 저장 | Cloudflare D1 | 서버리스 SQL |
| 실시간 영상 | Cloudflare Stream | 라이브 + VOD |
| 실시간 투표 | Firebase RTDB | 즉시 동기화 |
| 실시간 댓글 | Firebase RTDB | 즉시 동기화 |
| 이미지 업로드 | Cloudflare R2 | 선수 프로필 사진 |
| 알림 | 카카오 알림톡 API | 접수 확인 + 대회 알림 |

## 메인페이지 연결

- 홈 히어로 또는 별도 배너: **대회 현재 상태에 따른 CTA**
  - UPCOMING → `"2026 대회 곧 접수 시작"` 배너
  - REGISTRATION → `"지금 접수하세요"` 강조 CTA
  - LIVE → `"🔴 LIVE NOW"` 깜빡이는 배지 + 바로가기
  - RESULT → `"대회 결과 보기"` 링크

- Nav 메뉴에 `대회` 항목 추가 (LIVE일 때 🔴 인디케이터)
