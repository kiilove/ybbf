# 15. 협회 관계자(Contest Staff) 인증 및 접수관리 연동 가이드

협회 관계자들이 접속하는 `contest` 서브 프로젝트에서 관계자 계정 회원가입/인증을 처리하고, 부여된 대회 권한에 따라 신청서 정보와 입금 상태를 확인/제어할 수 있는 API 명세서입니다.

---

## 1. 개요 및 인증 방식

1. **세션 토큰 명칭 격리**:
   - 관계자 인증용 쿠키명은 **`contest_session_token`**입니다.
   - 쿠키를 이용할 수 없는 서브도메인이나 비연동 브라우저 환경에서는 요청 헤더에 `Authorization: Bearer <token>`을 전송하여 세션 인증을 우회 통과할 수 있습니다.
2. **보안 락(Lock) 정책**:
   - `contest_staffs` 테이블에 특정 스태프 계정의 `contestId`가 묶여 있는 경우(예: 특정 대회 담당자), 해당 계정으로 `GET /api/contest/registrations`를 호출할 시 **강제 필터링**이 적용되어 오직 지정된 대회의 접수 내역만 반환됩니다.
   - 입금 확인 및 취소 상태 토글 시에도, 매핑된 `contestId`와 대상 신청서의 `contestId`가 일치하지 않는 경우 **403 Forbidden** 오류가 반환됩니다.

---

## 2. API 명세

### [관계자] 2.1. 관계자 아이디 중복 확인
* **Endpoint**: `GET /api/contest/auth/check-username`
* **Query Parameters**:
  * `username` (string, 필수): 중복을 판독할 관계자 아이디
* **Response (HTTP 200)**:
  - **사용 가능한 경우**:
    ```json
    {
      "success": true,
      "available": true,
      "message": "사용 가능한 아이디입니다."
    }
    ```
  - **중복된 경우**:
    ```json
    {
      "success": true,
      "available": false,
      "message": "이미 사용 중인 아이디입니다."
    }
    ```

### [관계자] 2.2. 관계자 회원가입 (Signup)
* **Endpoint**: `POST /api/contest/auth/signup`
* **Content-Type**: `application/json`
* **Request Body**:
  ```json
  {
    "username": "staff_gildong",
    "password": "securepassword123",
    "name": "홍길동",                 // 필수 (내부적으로 복호화 가능 AES-256-GCM 암호화 후 name 필드에 보관)
    "phone": "010-1234-5678",          // 필수 (내부적으로 복호화 가능 AES-256-GCM 암호화 후 phone_encrypted 필드에 보관, 뒷4자리는 phone_last4에 보관)
    "contestId": "contest_2026_ybbf", // (선택) 담당 대회가 지정되어 있을 시 기입
    "email": "gildong@example.com",   // (선택) 이메일
    "position": "심판위원장",            // (선택) 직위
    "isReferee": true,                // (선택) 심판 자격 여부 (true/false)
    "refereeGrade": "1급",             // (선택) 심판 자격 급수
    "profilePhotoUrl": "data:image/png;base64,...", // (선택) 프로필 사진
    "businessIntro": "용인 짐 헬스장 대표",          // (선택) 사업체 소개
    "snsLinks": {                                  // (선택) 유연한 소셜 링크
      "instagram": "https://instagram.com/...",
      "youtube": "https://youtube.com/..."
    }
  }
  ```
* **Response (HTTP 200)**:
  ```json
  {
    "success": true,
    "message": "관계자 계정이 생성되었습니다. 관리자 승인 후 사용 가능합니다."
  }
  ```

### [관계자] 2.3. 관계자 로그인 (Login)
* **Endpoint**: `POST /api/contest/auth/login`
* **Content-Type**: `application/json`
* **Request Body**:
  ```json
  {
    "username": "staff_gildong",
    "password": "securepassword123"
  }
  ```
* **Response (HTTP 200)**:
  - 성공 시 `Set-Cookie: contest_session_token=<token>` 헤더가 발행됩니다.
  ```json
  {
    "success": true,
    "token": "d748f32c-3b9e-4e8c-8f92-9382f1b4c901",
    "staff": {

      "username": "staff_gildong",
      "name": "홍길동",                 // 실시간 복호화되어 평문으로 응답
      "role": "staff",
      "contestId": "contest_2026_ybbf",
      "phone": "010-1234-5678",          // 실시간 복호화되어 평문으로 응답
      "email": "gildong@example.com",
      "position": "심판위원장",
      "isReferee": true,
      "refereeGrade": "1급",
      "profilePhotoUrl": "data:image/png;base64,...",
      "businessIntro": "용인 짐 헬스장 대표",
      "snsLinks": {
        "instagram": "https://instagram.com/...",
        "youtube": "https://youtube.com/..."
      }
    }
  }
  ```

### [관계자] 2.4. 관계자 세션 정보 확인 (Me)
* **Endpoint**: `GET /api/contest/auth/me`
* **Headers**: `Authorization: Bearer <contest_session_token>` 또는 관계자 세션 쿠키
* **Response (HTTP 200)**:
  ```json
  {

    "username": "staff_gildong",
    "name": "홍길동",                   // 실시간 복호화되어 평문으로 응답
    "role": "staff",
    "contestId": "contest_2026_ybbf",
    "phone": "010-1234-5678",             // 실시간 복호화되어 평문으로 응답
    "email": "gildong@example.com",
    "position": "심판위원장",
    "isReferee": true,
    "refereeGrade": "1급",
    "profilePhotoUrl": "data:image/png;base64,...", // (선택) 프로필 이미지 데이터
    "businessIntro": "용인 특례시 소재 피트니스 클럽 운영 중...", // (선택) 사업자 소개
    "snsLinks": {                                  // (선택) 유연한 소셜 링크 (인스타, 유튜브, 홈페이지 등)
      "instagram": "https://instagram.com/...",
      "youtube": "https://youtube.com/...",
      "homepage": "https://..."
    }
  }
  ```

### [관계자] 2.5. 회원가입 신청 완료 후 추가 프로필 정보 입력 (Additional Info)
* **Endpoint**: `POST /api/contest/auth/additional-info`
* **Content-Type**: `application/json`
* **Request Body**:
  ```json
  {
    "username": "staff_gildong",                 // 필수 (대상 관계자 식별용)
    "profilePhotoUrl": "data:image/png;base64,...", // (선택) 프로필 이미지
    "businessIntro": "용인 짐 헬스장 대표",          // (선택) 사업자 소개
    "snsLinks": {                                  // (선택) 다양한 소셜 링크 (유연하게 키-값 확장 가능)
      "instagram": "https://instagram.com/...",
      "youtube": "https://youtube.com/...",
      "blog": "https://blog.naver.com/..."
    }
  }
  ```
* **Response (HTTP 200)**:
  ```json
  {
    "success": true,
    "message": "임원 추가 정보가 저장되었습니다."
  }
  ```

### [관계자] 2.6. 관계자 비밀번호 검증 (Verify Password)
* **Endpoint**: `POST /api/contest/auth/verify-password`
* **Headers**: `Authorization: Bearer <contest_session_token>` 또는 관계자 세션 쿠키
* **Content-Type**: `application/json`
* **Request Body**:
  ```json
  {
    "password": "input_password_here" // 필수
  }
  ```
* **Response (HTTP 200)**:
  - 검증 성공 시:
    ```json
    {
      "success": true,
      "message": "비밀번호가 확인되었습니다."
    }
    ```
  - 검증 실패 시 (HTTP 400):
    ```json
    {
      "success": false,
      "error": "비밀번호가 일치하지 않습니다."
    }
    ```

### [관계자] 2.7. 관계자 로그아웃 (Logout)
* **Endpoint**: `POST /api/contest/auth/logout`
* **Response (HTTP 200)**:
  - 세션 쿠키가 만료 및 삭제 처리됩니다.
  ```json
  {
    "success": true,
    "message": "로그아웃되었습니다."
  }
  ```

### [최고 관리자 전용] 2.8. 관계자 스태프 목록 조회 및 관리
*최고 관리자 세션인 `Authorization: Bearer <admin_token>` 또는 관리자 세션 쿠키가 요구됩니다.*

* **스태프 등록**: `POST /api/admin/contest-staffs`
  - Request Body:
    ```json
    {
      "username": "staff_gildong",
      "password": "securepassword123",
      "name": "홍길동",
      "phone": "010-1234-5678",
      "role": "staff",                     // "staff" 또는 "admin"
      "status": "active",                  // (선택, 기본값 "active") "active" | "inactive" | "pending"
      "contestId": "contest_2026_ybbf",     // (선택)
      "email": "gildong@example.com",       // (선택)
      "position": "심판위원장",                // (선택)
      "isReferee": true,                    // (선택)
      "refereeGrade": "1급",                 // (선택)
      "profilePhotoUrl": "...",            // (선택)
      "businessIntro": "용인 짐 헬스장 대표",      // (선택)
      "snsLinks": {                        // (선택)
        "instagram": "https://instagram.com/..."
      }
    }
    ```
  - Response (HTTP 200): `{ "success": true, "message": "관계자 계정이 성공적으로 등록되었습니다.", "uid": "generated-uuid" }`

* **스태프 목록 조회**: `GET /api/admin/contest-staffs`
  - Query Parameters (선택):
    - `keyword` (string): 아이디, 이름, 연락처 검색어
    - `status` (string): 계정 상태 (`all`, `active`, `inactive`, `pending`)
    - `role` (string): 권한 (`all`, `staff`, `admin`)
  - Response (HTTP 200):
    ```json
    {
      "success": true,
      "total": 1,
      "staffs": [
        {
          "uid": "d748f32c-3b9e-4e8c-8f92-9382f1b4c901",
          "username": "staff_gildong",
          "name": "홍길동",
          "phone": "010-1234-5678",
          "role": "staff",
          "status": "active",
          "contestId": null,
          "email": "gildong@example.com",
          "position": "심판위원장",
          "isReferee": true,
          "refereeGrade": "1급",
          "profilePhotoUrl": "...",
          "businessIntro": "...",
          "snsLinks": { "instagram": "..." },
          "createdAt": "2026-06-20T10:00:00.000Z"
        }
      ]
    }
    ```

* **스태프 정보 수정**: `PUT /api/admin/contest-staffs/:uid`
  - Request Body:
    ```json
    {
      "name": "홍길동 수정",
      "phone": "010-9999-8888",
      "role": "staff",
      "status": "active",
      "contestId": "contest_2026_ybbf",
      "email": "new_email@example.com",
      "position": "수석 심판위원",
      "isReferee": true,
      "refereeGrade": "S급",
      "profilePhotoUrl": "...",
      "businessIntro": "...",
      "snsLinks": { "instagram": "..." },
      "password": "newpassword123" // (선택, 변경 시에만 기입)
    }
    ```
  - Response (HTTP 200): `{ "success": true, "message": "관계자 정보가 수정되었습니다." }`

* **계정 상태 변경**: `PATCH /api/admin/contest-staffs/:uid/status`
  - Request Body: `{ "status": "inactive" }` (`"active"`, `"inactive"`, `"pending"`)
  - Response (HTTP 200): `{ "success": true, "message": "계정 상태가 'inactive'로 변경되었습니다." }`

* **비밀번호 초기화**: `POST /api/admin/contest-staffs/:uid/reset-password`
  - Request Body: `{ "newPassword": "tempPassword!123" }` (선택, 없을 경우 8자리 무작위 생성)
  - Response (HTTP 200): `{ "success": true, "message": "비밀번호가 성공적으로 초기화되었습니다.", "tempPassword": "tempPassword!123" }`

* **스태프 삭제**: `DELETE /api/admin/contest-staffs/:uid`
  - Response (HTTP 200): `{ "success": true, "message": "관계자 계정이 삭제되었습니다." }`

* **참가 접수 내역 삭제**: `DELETE /api/admin/invoices/:id`
  - Response (HTTP 200): `{ "success": true, "message": "참가 접수 내역이 성공적으로 삭제되었습니다." }`

### [관계자 전용] 2.6. 관계자 접수 현황 제어
*관계자 세션인 `Authorization: Bearer <contest_session_token>` 또는 관계자 세션 쿠키가 요구됩니다.*

#### 2.6.1. 접수 목록 조회
* **Endpoint**: `GET /api/contest/registrations`
* **Query Parameters**:
  * `contestId` (string, 선택): 조회할 대회 식별자 (※ 관계자 권한에 특정 대회 ID가 묶여 있는 경우 이 파라미터와 상관없이 강제 필터링 락이 적용됩니다.)
  * `keyword` (string, 선택): 이름 또는 연락처 검색 키워드
  * `isPriceCheck` (boolean/string, 선택): 입금 완료 여부 (`true` / `false` / `1` / `0`)
  * `isCanceled` (boolean/string, 선택): 취소 여부 (`true` / `false` / `1` / `0`)
* **Response (HTTP 200)**:
  ```json
  [
    {
      "id": "invoice_uuid_123",
      "playerUid": "user_abc",
      "playerName": "홍길동",
      "playerGender": "m",
      "playerBirth": "1998-05-12",
      "playerTel": "010-1234-5678",
      "playerGym": "용인 헬스장",
      "joins": [
        {
          "contestCategoryId": "cat_physique",
          "contestCategoryTitle": "피지크",
          "contestGradeId": "grade_175",
          "contestGradeTitle": "-175cm"
        }
      ],
      "contestPriceTotal": 80000,
      "isPriceCheck": true,
      "isCanceled": false,
      "contestId": "contest_2026_ybbf",
      "submittedAt": "2026-06-20T11:42:00.000Z"
    }
  ]
  ```

#### 2.6.2. 특정 접수 건의 입금 확인 여부 수정
* **Endpoint**: `POST /api/contest/registrations/:id/check`
* **Request Body**:
  ```json
  {
    "isPriceCheck": true // 또는 false
  }
  ```
* **Response (HTTP 200)**:
  ```json
  {
    "success": true,
    "message": "입금 확인 상태가 수정되었습니다."
  }
  ```

#### 2.6.3. 특정 접수 건의 취소 상태 수정
* **Endpoint**: `POST /api/contest/registrations/:id/cancel`
* **Request Body**:
  ```json
  {
    "isCanceled": true // 또는 false
  }
  ```
* **Response (HTTP 200)**:
  ```json
  {
    "success": true,
    "message": "접수 취소 상태가 수정되었습니다."
  }
  ```
