# 13. 사전계측자료 연동 가이드

대회에 참가 신청을 완료한 선수가 사전계측용 미디어 자료(R2 URL)를 제출하고, 어드민 관리 페이지에서 이를 검토할 수 있는 단독 기능의 연동 명세입니다.

---

## 1. 개요 및 흐름

1. **선수 본인인증 및 검증**:
   - 선수가 마이페이지 또는 전용 업로드 페이지에서 대회(`contestId`)를 선택하고 자신의 정보(UID 등)로 사전계측 접수 자격 여부를 체크합니다.
   - `GET /api/pre-measurement/status` API를 호출하여 `{ registered: true }`일 경우에만 미디어 업로드 입력창을 활성화합니다.
2. **미디어 업로드**:
   - 미디어 워커(`ybbf-media-worker`의 `POST /api/upload?folder=pre_measurements`)를 호출하여 이미지 또는 동영상을 R2 스토리지에 업로드하고 서빙 URL을 획득합니다.
3. **자료 메타데이터 제출**:
   - `POST /api/pre-measurement` API를 통해 R2 미디어 주소와 선수 메타데이터(이름, 전화번호, contestId, playerUid 등)를 D1에 최종 제출합니다.
4. **관리자 검토 및 관리**:
   - 관리자는 어드민 페이지에서 특정 대회(`contestId`)를 선택하고 `GET /api/admin/pre-measurement/list?contestId=...`를 호출하여 선수들의 계측 자료 목록을 한눈에 검토합니다.
   - 오등록되거나 불량한 계측 자료는 `DELETE /api/admin/pre-measurement/:id` API를 호출하여 삭제 처리할 수 있습니다.

---

## 2. API 상세 명세

### [선수용] 2.1. 사전계측 상태 및 제출 조회
* **Endpoint**: `GET /api/pre-measurement/status`
* **Query Parameters**:
  * `contestId` (string, 필수): 대회 식별자
  * `playerUid` (string, 필수): 선수의 고유 식별자 (UID)
* **Response**:
  * **접수 이력 없음**:
    ```json
    {
      "registered": false,
      "submitted": false,
      "data": null
    }
    ```
  * **접수되었으나 계측 미제출**:
    ```json
    {
      "registered": true,
      "submitted": false,
      "data": null
    }
    ```
  * **접수되었고 계측자료도 제출 완료**:
    ```json
    {
      "registered": true,
      "submitted": true,
      "data": {
        "id": "contestId_playerUid",
        "contestId": "...",
        "playerUid": "...",
        "playerName": "홍길동",
        "playerTel": "010-1234-5678",
        "mediaUrl": "https://ybbf-media-worker.jbkim.workers.dev/pre_measurements/xyz.mp4",
        "mediaType": "video",
        "createdAt": "2026-06-13 09:34:00"
      }
    }
    ```

---

### [선수용] 2.2. 사전계측자료 최종 제출
* **Endpoint**: `POST /api/pre-measurement`
* **Content-Type**: `application/json`
* **Request Body**:
  ```json
  {
    "contestId": "contest_abc",
    "playerUid": "user_xyz",
    "playerName": "홍길동",
    "playerTel": "010-1234-5678",
    "mediaUrl": "https://ybbf-media-worker.jbkim.workers.dev/pre_measurements/xyz.mp4",
    "mediaType": "video" 
  }
  ```
  *(참고: `mediaType`은 `'video'` 또는 `'image'`로 고정하여 전달합니다.)*
* **Response**:
  * **성공 (HTTP 200)**:
    ```json
    {
      "success": true,
      "message": "사전계측자료가 제출되었습니다."
    }
    ```
  * **접수 내역 없음 (HTTP 403)**:
    ```json
    {
      "error": "해당 대회에 접수 완료된 내역을 찾을 수 없습니다."
    }
    ```

---

### [관리자용] 2.3. 대회별 사전계측자료 전체 조회
* **Endpoint**: `GET /api/admin/pre-measurement/list`
* **Headers**: `Authorization: Bearer <session_token>` 또는 관리자 세션 쿠키
* **Query Parameters**:
  * `contestId` (string, 필수): 조회하고자 하는 대회 식별자
* **Response (HTTP 200)**:
  ```json
  [
    {
      "id": "contest_abc_user_xyz",
      "contestId": "contest_abc",
      "playerUid": "user_xyz",
      "playerName": "홍길동",
      "playerTel": "010-1234-5678",
      "mediaUrl": "https://ybbf-media-worker.jbkim.workers.dev/pre_measurements/xyz.mp4",
      "mediaType": "video",
      "createdAt": "2026-06-13 09:34:00"
    }
  ]
  ```

---

### [관리자용] 2.4. 사전계측자료 삭제
* **Endpoint**: `DELETE /api/admin/pre-measurement/:id`
* **Headers**: `Authorization: Bearer <session_token>` 또는 관리자 세션 쿠키
* **Path Parameters**:
  * `id` (string, 필수): 사전계측 레코드 식별자 (`contestId_playerUid` 형식)
* **Response (HTTP 200)**:
  ```json
  {
    "success": true,
    "message": "사전계측 자료가 성공적으로 삭제되었습니다."
  }
  ```

---

## 3. 프론트엔드 및 어드민 구현 가이드

### 3.1. 📱 프론트엔드 에이전트 지시사항 (`src/` 경로)
1. **페이지 신설**: `src/pages/PreMeasurementUploadPage.tsx`
2. **구현 요구사항**:
   - **대회 선택 및 검증**: 드롭다운에서 대회(`contestId`)를 선택하고, 로그인된 유저의 `playerUid`를 조합하여 `GET /api/pre-measurement/status` 호출.
   - **상태 제어**:
     - `registered: false` ➔ "참가 신청 내역이 확인되지 않습니다. 먼저 대회 참가를 신청해 주세요." 안내 출력 및 업로드 차단.
     - `registered: true, submitted: false` ➔ 자료 제출 폼 활성화.
     - `registered: true, submitted: true` ➔ 기제출된 미디어 미리보기 렌더링 및 "이미 제출 완료되었습니다. 재제출 시 기존 자료를 덮어씁니다." 안내와 함께 폼 활성화.
   - **미디어 파일 업로드**:
     - 파일 선택 인풋 구성 (비디오 또는 이미지 형식 제한).
     - 파일 선택 시 `POST https://ybbf-media-worker.jbkim.workers.dev/api/upload?folder=pre_measurements` API로 업로드하여 R2 주소 획득.
   - **자료 제출**:
     - 획득한 R2 URL, 미디어 타입(video/image), 기타 인적 사항을 바디에 담아 `POST /api/pre-measurement` API를 최종 호출하여 완료 처리.

### 3.2. ⚙️ 어드민 에이전트 지시사항 (`admin/` 경로)
1. **페이지 신설**: `admin/src/pages/PreMeasurementAdminPage.tsx`
2. **구현 요구사항**:
   - **대회 셀렉터**: 대회를 선택할 수 있는 드롭다운 메뉴를 최상단에 배치합니다.
   - **목록 그리드**: 선택된 대회에 따라 `GET /api/admin/pre-measurement/list?contestId=...`를 조회하여 리스트업합니다.
   - **미디어 검토 기능**:
     - `mediaType === 'video'`일 경우, 동영상 링크 클릭 시 모달 플레이어나 새 창에서 즉시 비디오(`<video src={mediaUrl} controls />`)가 재생되도록 구현합니다.
     - `mediaType === 'image'`일 경우, 썸네일 노출 및 클릭 시 라이트박스(이미지 크게 보기)로 볼 수 있게 합니다.
   - **데이터 삭제**: 각 줄 우측에 "삭제" 버튼을 배치하고, 클릭 시 컨펌 창을 띄운 뒤 `DELETE /api/admin/pre-measurement/:id` API를 연동해 관리합니다.
