# YBBF 유스 페이지 기획 (`/youth`)

> **디자인 참조: Lando Off-Track의 Projects 섹션**
> 각 프로젝트를 독립적인 에디토리얼 블록으로 소개하는 방식 차용

---

## 컨셉

K리그 유스, 농구 유스, 야구 유스 같은 **공식 유스 시스템**.
고등학생 대상 (중학생까지 확대 목표).

### 핵심 가치: **소속감**

학교에는 보디빌딩 교과목이 없다.
본인이 운동하는 체육관이 **클럽**이 되고,
그 클럽이 **용인시 소속**이 되며,
곧 **경기도의 선수**가 되는 시스템.

```
🏋️ 체육관(클럽) → 🏙️ 용인시(YBBF) → 🗺️ 경기도 대표
```

> 현재 YBBF는 용인시 범위이므로 경기도까지 건드리지 않되,
> 스토리라인은 경기도까지 연결.

---

## 섹션 구성

### 섹션 1: 히어로
- **"YBBF YOUTH"** 거대 타이포
- 부제: `"NEXT GENERATION OF CHAMPIONS"`
- 배경: 젊은 선수들의 트레이닝 장면 (흑백/고대비)
- On-Track의 공격적 에너지 + 희망적 톤

### 섹션 2: 시스템 소개 (비주얼 다이어그램)
- Off-Track Projects 스타일: 아이콘 + 텍스트 블록
- 3단계 구조를 시각적으로 표현:
  1. **클럽(체육관)** — 나의 훈련 기지
  2. **YBBF(용인시)** — 나의 소속 협회
  3. **경기도** — 내가 대표하는 지역
- 스크롤 시 순차 등장 애니메이션 (GSAP stagger)

### 섹션 3: 등록 클럽 목록
- 카드 그리드 (2~3컬럼)
- 카드 내용: 클럽명 / 위치 / 소속 선수 수 / 대표 코치
- 미니멀 디자인, 호버 시 네온 라임 보더
- 지도 연동은 추후 Phase 확장

### 섹션 4: 유스 로스터 (선수 명단)
- 소속 클럽별 / 학교별 필터
- 선수 카드:
  - **"YBBF YOUTH" 공식 뱃지** 강조 (소속감의 핵심)
  - 이름, 학년, 소속 클럽, 체급
- 목표: "나도 여기 이름이 올라가 있다"는 자부심

### 섹션 5: 유스 성과/미디어
- 유스 부문 대회 결과 하이라이트
- 미래 스타 프리뷰 카드

## 데이터 모델

```typescript
interface YouthAthlete {
  id: string;
  name: string;
  grade: string;          // 고1, 고2, 고3
  school: string;
  clubId: string;         // 소속 클럽 ID
  class: string;          // 체급
  badge: 'YBBF_YOUTH';    // 공식 뱃지
  achievements?: string[];
}

interface YouthClub {
  id: string;
  name: string;           // 체육관명
  location: string;       // 용인시 처인구...
  coach: string;          // 대표 코치
  athleteCount: number;
  region: '용인시';       // 현재는 용인시 고정
}
```
