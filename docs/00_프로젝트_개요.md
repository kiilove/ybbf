# YBBF 플랫폼 프로젝트 개요

> **용인시보디빌딩협회(YBBF) 공식 플랫폼**
> 목표: 전 세계 보디빌딩 협회 홈페이지 중 **비주얼 1등**

---

## 프로젝트 비전

보디빌딩을 F1 레이싱처럼 **프리미엄하고 역동적인 스포츠**로 연출한다.
대회 입상자를 **"레전드"**로 네이밍하고, 유스 시스템을 통해 차세대 챔피언을 육성하며,
미디어 허브를 통해 공식 콘텐츠를 제공하는 **원스톱 플랫폼**.

## 디자인 레퍼런스

- **Primary**: [landonorris.com](https://landonorris.com)
- 메인페이지는 Lando 홈을 참조하여 이미 구현 완료
- 서브페이지는 On-Track / Off-Track / Calendar 디자인 패턴을 차용

## 기술 스택

| 구분 | 기술 |
|------|------|
| Core | React 19 + TypeScript + Vite |
| Styling | Tailwind CSS v4 + CSS Variables |
| Animation | GSAP + ScrollTrigger + Lenis + SplitType |
| Graphics | OGL (WebGL 셰이더) |
| Routing | React Router DOM |
| Fonts | Anton (Display) + Inter + Noto Sans KR |
| Icons | Lucide React (SVG only, 이모지 금지) |

## 핵심 디자인 원칙

1. **Scale is Power** — 숫자와 타이틀은 뷰포트의 절반 이상 차지
2. **Black is Premium** — 올블랙 배경 + 네온 라임(`#CCFF00`) 포인트
3. **Editorial Layout** — 비대칭 레이아웃, 이미지-텍스트 오버랩
4. **Metadata as Design** — 체급/키/몸무게 같은 데이터를 장식적 요소로 활용
5. **Personal Touch** — 선수 서명, 핸드라이팅 폰트로 친밀감
