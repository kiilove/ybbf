# 사이트맵 & 페이지 구조

---

## 전체 사이트맵

```
🏠 메인 (/)
├── 🏆 레전드 (/legends)          ← 최고 우선순위
│   └── 👤 레전드 상세 (/legends/:id)
├── 🎬 미디어 (/media)            ← 높은 우선순위
├── ⚡ YBBF 유스 (/youth)         ← 높은 우선순위
├── 🏛️ 협회 소개 (/about)         ← 낮은 우선순위
└── 🛍️ 스토어 (/store)            ← Phase 2
```

## Lando Norris → YBBF 디자인 매핑

| Lando 페이지 | YBBF 페이지 | 차용 포인트 |
|---|---|---|
| **On-Track** | **레전드** | 거대 숫자 스탯, 다크 테이블, 커리어 데이터 |
| **Off-Track** | **미디어 + 유스** | 에디토리얼 매거진 레이아웃, 비대칭 그리드 |
| **Calendar** | **대회 일정 (추후)** | 풀스크린 다크 테이블, 볼드 타이포 |
| **Menu** | **Nav 리팩토링** | 흑백 사진 그리드 + 거대 메뉴 텍스트 |

## 메인페이지 섹션 ↔ 서브페이지 연결

메인페이지의 각 섹션은 서브페이지의 **"예고편(Trailer)"** 역할을 한다.

| 현재 섹션 | 리브랜딩 | 연결 서브페이지 | 변경 수준 |
|-----------|----------|----------------|-----------|
| Hero + WebGL | 유지 | - | 변경 없음 |
| Manifesto | 유지 + 링크 추가 | `/about` | 최소 |
| HorizontalGallery | **"MEDIA"** 프리뷰 | `/media` | 콘텐츠 교체 |
| StageSections ON | **"LEGENDS"** 프리뷰 | `/legends` | 리디자인 |
| StageSections OFF | **"YBBF YOUTH"** 프리뷰 | `/youth` | 리디자인 |
| HallOfFame | **"LEGEND COLLECTION"** | `/legends` | 리브랜딩 |
| StoreSection | 유지 | `/store` | 변경 없음 |
| Partners | 유지 | - | 변경 없음 |
| Socials | 유지 | - | 변경 없음 |
| Footer | 네비 링크 업데이트 | 전체 | 최소 |

## Nav 메뉴 구조 (리팩토링)

현재 메뉴 항목:
```
홈 / 무대 위 / 무대 뒤 / 파트너십 / 일정표
```

변경 후:
```
홈 / 레전드 / 미디어 / YBBF 유스 / 스토어
```

> [!NOTE]
> 협회 소개(`/about`)는 메인 메뉴에 넣지 않고 Footer 링크로 처리.
> 스토어는 Nav 우측 상단에 별도 CTA 버튼으로 유지 (Lando 사이트의 STORE 버튼 참조).
